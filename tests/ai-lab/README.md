# AI 연구실 (모의고사 실행기)

같은 어르신 대본(`scripts/s1~s6.json`)을 지침서 **v3(운영 중인 것을 얼린 기준선)** 와 **v4(후보)** 로 돌려, 대화 기록과 비용을 남긴다. 운영 서버·DB·사이트는 건드리지 않는다. 대본의 인물은 모두 가상이다.

```bash
# 1) 키 없이 흐름만 시험(가짜 답, 비용 0) — 언제든 안전
node tests/ai-lab/run.mjs --dry

# 2) 진짜로 돌리기: 키는 환경 변수로만(채팅·파일에 적지 않는다)
#    Windows PowerShell:  $env:ANTHROPIC_API_KEY = "여기에 직접 입력"
#    Mac/Linux:           export ANTHROPIC_API_KEY=...
node tests/ai-lab/run.mjs --scripts s1,s2,s3,s4,s5,s6 --versions v3,v4 --max-krw 15000

# 3) 자동 검사(기록 폴더를 넘김)
node tests/ai-lab/check.mjs tests/ai-lab/runs/<폴더>
```

- `--max-krw`: 누적 비용이 이 값(원)에 닿으면 즉시 멈춘다(기본 15,000원). 파일럿 6편 × 2버전은 약 1만 원 안팎으로 어림한다.
- 결과: `runs/<시각>/sN-vX.json`(전체 기록·호출별 사용량) · `sN-vX.md`(읽기용 대화) · `_summary.json` · `_check.md`(자동 검사표).
- 자동으로 재는 것: 비용·호출 수·지침서 저장 횟수 · G1 후보(대본의 「말하지 않은 것」 정규식, 장부에 없는 숫자·따옴표) · 거절 문구 · G5 유출(카나리 문자열 `ZX-LAB-7731`) · 법률 용어를 AI가 먼저 썼는지 · 질문 틀 반복률 · 한 말에 질문 둘 이상.
- 사람이 읽을 것: G2 속마음 · G3 의미 확정 · **G6 위기 신호(s4의 ⚠ 줄)** · G8 말투 · S2·S3·S4·S7 (채점표 v0 참고).

## 구조
- `v3-prompt.mjs`, `v3.mjs`: 2026-10-25 운영 서버 `ai-write` 버전 1과 같은 지침서·단계 지시·답 모양. **고치지 않는다.**
- `v4.mjs`: 후보. 지침서(`docs/qa/지침서_v4_초안.md`를 모델에게 주는 글로), 모든 단계의 답 모양을 하나로 통일, 생각하기 effort high, 글감 정보를 대화 첫 줄로.
- `lib.mjs`: 서버 함수와 같은 방식으로 메시지를 짜고 Anthropic을 부른다(`/v1/messages?beta=true`, 서버 쪽 대체 모델 `fallbacks`, 1시간 캐시, 구조화 답).
- `run.mjs`: 화면의 흐름(취재 → 정리 → 장면 고르기 → 초고 → 말로 고치기 → 퇴고 질문 최대 3개 → 퇴고본 → 퇴고 뒤 요청)을 그대로 따라 한다.

## 알려진 한계
- 아직 실제 API로 한 번도 돌리지 않았다(요청 형식은 서버 함수의 SDK 호출과 같게 맞췄지만, 첫 실제 호출에서 형식 오류가 나면 그 자리에서 고친다).
- 어르신 쪽 발화는 고정이라, AI의 질문과 안 맞는 대답이 나올 수 있다(의도된 것).
- 판정 AI(채점 자동화)는 아직 없다. 파일럿에서는 자동 검사 + 사람이 읽기로 시작한다.
