# 인물대백과사 운영 수첩

## 1. 매일 점검 (5분)
1. 서가·내 서재·스튜디오가 열리는지(각 주소 한 번씩)
2. 관리자 페이지 「처리할 신고」 0건인지 — 있으면 당일 처리
3. 새 회원·새 책 수가 평소와 비슷한지(갑자기 폭증 = 스팸·공격 의심)
4. Supabase 대시보드: 저장 용량·전송량(Bandwidth)·DB 크기가 한도의 80% 미만인지
5. Supabase 로그: 로그인 실패·오류가 갑자기 늘지 않았는지
6. 서가에 새로 공개된 책 제목을 훑어보기(부적절한 내용)
7. 가입 확인 메일이 정상 발송되는지(주 1회 테스트 계정으로)

## 2. 매주
- 백업 파일이 실제로 만들어졌는지 확인(날짜·크기)
- Supabase 보안 권고(Advisors) 새 항목 확인
- 휴지통에서 30일 지난 책 정리 여부 결정

## 3. 매월
- 백업 복원 연습(테스트 프로젝트에 되살려 보기) — 복원해 본 백업만 믿는다
- 비용 확인(Supabase·도메인·GitHub)
- 관리자 계정 목록·비밀번호·2단계 인증 점검
- 외부 부품(THIRD_PARTY_NOTICES.md) 보안 공지 확인

## 4. 매년
- 도메인(가비아) 자동 연장·결제 카드 유효기간
- 약관·개인정보처리방침 법 개정 반영
- "서비스 종료 시 책 반환" 계획 문서 갱신
