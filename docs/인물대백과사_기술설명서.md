## 1. 개요

인물대백과사는 일반인이 **글·사진·영상·노래를 엮어 실제 책 판형의 자서전**을 만들고, 이를 **화면(전자책)과 종이(인쇄본) 양쪽으로 출판**할 수 있는 웹 기반 플랫폼입니다.

핵심 차별점은 세 가지입니다.

1. **책 판형 기반 편집**: 블로그식 스크롤이 아닌, 신국판(152×225mm) 지면 단위로 편집합니다.
2. **하이브리드 출판**: 하나의 원고로 넘겨 보는 전자책과, 영상·노래가 QR로 연결되는 종이책을 함께 만듭니다.
3. **작가 권리 중심 설계**: 저작권 보호, 공개 범위 통제, 즉시 파기를 기본으로 갖췄습니다.

## 2. 문제와 해결

| 문제 | 기존 대안의 한계 | 인물대백과사의 해결 |
|---|---|---|
| 자서전 제작이 어렵고 비싸다 | 대필·출판 대행은 수백만 원대 | 견본 틀과 자동 조판으로 스스로 완성 |
| 영상·노래는 종이책에 못 담는다 | 종이책과 디지털이 분리됨 | 인쇄 시 미디어 자리에 QR 자동 삽입 |
| 블로그·SNS는 "책"이 아니다 | 스크롤형, 판형 없음, 휘발성 | 실제 판형 지면 + 책장 넘김 열람 + 파일 소장 |
| 개인 기록이 퍼질까 걱정된다 | 공개 범위 통제가 약함 | 나만 보기 / 비밀 링크 / 서가 공개 3단계 |

## 3. 핵심 기술

### 3.1 판형 기반 페이지 모델
- 모든 요소(글상자, 사진, 영상, 노래)를 **밀리미터 좌표**로 저장합니다. 화면 크기와 상관없이 같은 지면이 재현됩니다.
- 화면 렌더링은 컨테이너 상대 단위를 써서, 휴대폰부터 인쇄까지 **한 원본, 동일한 조판**을 보장합니다.
- 고정 여백(좌우 16mm, 상하 18mm)과 12pt 기본 활자로 출판물 수준의 지면을 기본값으로 제공합니다.

### 3.2 글 흐름(리플로우) 엔진
- 글이 지면을 넘치면 **글자 단위로 넘친 지점을 찾아**(이진 탐색) 단어 경계에서 자르고, 다음 쪽으로 이어 붙입니다.
- 앞쪽에 빈자리가 생기면 뒤쪽 글을 **다시 끌어오고**, 커서 위치를 보존합니다.
- 워드프로세서·조판 프로그램 수준의 기능을 브라우저에서 구현했습니다.

### 3.3 미디어 자동 배치와 견본 틀
- 쪽 종류(글/사진/영상/노래)별 「제목·콘텐츠·설명」 틀을 제공합니다.
- 미디어를 넣으면 **① 같은 종류의 빈 자리 → ② 현재 쪽의 빈 공간 → ③ 새 쪽** 순서로 자동 배치합니다. 지우면 원래 틀의 자리가 되살아납니다.
- 올리기 전에 브라우저에서 사진을 자동 압축(긴 변 1920px, 약 1.5MB 이하)해서 저장 비용과 로딩 시간을 줄입니다. 영상은 60초 이하로 제한합니다.

### 3.4 책장 넘김 열람기
- 넓은 화면에서는 **두 쪽 펼침**, 좁은 화면에서는 한 쪽씩 보여 주는 반응형 열람기입니다.
- 3D 책장 넘김 효과, 키보드·휠·스와이프 조작을 지원합니다.
- **보이는 쪽만 그리는 지연 렌더링**으로, 미디어가 많은 책도 가볍게 열립니다.
- 노래는 책 단위 단일 재생기로 관리해서 쪽을 넘겨도 끊기지 않습니다.
- 접근성: 3단계 글자 확대(시니어 이용자 고려), 「동작 줄이기」 설정을 존중합니다.

### 3.5 하이브리드 인쇄 (종이책 + QR)
- 인쇄용 출력 시 영상·노래 자리를 **QR 코드로 자동 치환**합니다. QR 판독 시험으로 인식을 확인했습니다.
- QR은 미디어 고유 번호를 가리켜서 **쪽 순서가 바뀌어도 링크가 유지**됩니다.
- 비공개 책은 비밀 링크 주소로 QR을 만들고, 링크를 폐기하면 QR도 함께 무효가 됩니다.

### 3.6 초안·발행 분리 출판 모델
- 작가가 쓰는 **초안**과 독자가 보는 **발행본**을 분리 저장합니다. 고치는 중인 내용이 독자에게 노출되지 않습니다.
- 공개 범위는 3단계입니다: 나만 보기 / 비밀 링크(추측 불가능한 32자 토큰) / 공개 서가.

### 3.7 저작권 보호
- 열람 화면에서 복사·인쇄·저장·끌어가기·우클릭을 차단하고, 영상·음원의 내려받기 메뉴를 제거했습니다.
- 미디어 파일은 비공개 저장소에 두고 **유효 시간 1시간의 서명 주소**로만 제공합니다.
- 한계: 화면 녹화·카메라 촬영은 웹 기술로 막을 수 없습니다. 영상·음원은 향후 DRM 도입이 가능한 구조입니다.

## 4. 보안·개인정보 아키텍처

- **데이터베이스 행 단위 보안(RLS)**: 접근 권한을 화면이 아니라 DB 규칙으로 강제합니다. "본인 책은 본인만, 공개된 책만 모두에게."
- **권한 분리**: 관리자 판별 함수는 외부 API에 노출되지 않는 별도 스키마에 두고, 관리자 화면은 공개 책만 다룹니다.
- **서버 비밀 열쇠 격리**: 고권한 작업(비밀 링크 열람, 회원 탈퇴)은 서버 함수 안에서만 수행합니다.
- **즉시 파기**: 탈퇴하면 계정, 책, 파일을 서버에서 즉시 삭제합니다. 실서버 시험 계정으로 검증했고, 다른 회원 데이터에 영향이 없음을 확인했습니다.
- **입력 정제**: 모든 글은 허용 목록 방식으로 정제해서 스크립트 삽입 공격을 막습니다.
- **공급망 보안**: 외부 라이브러리를 저장소에 고정 보관하고 지문(SHA-256)을 관리합니다. 외부 CDN에 의존하지 않습니다.
- 데이터는 **대한민국(서울) 리전**에 저장됩니다. 이용약관과 개인정보 처리방침, 필수 동의, 동의 버전 기록을 갖췄습니다.

## 5. 시스템 구성

| 계층 | 구성 |
|---|---|
| 화면 | 정적 웹(HTML·JavaScript), 별도 빌드나 프레임워크 없이 경량 운영 |
| 백엔드 | Supabase (PostgreSQL 17, 인증, 객체 저장소, 서버 함수) |
| 배포 | 정적 호스팅(GitHub Pages) + 자체 도메인 |
| 이식성 | 표준 PostgreSQL + S3 호환 저장소. 특정 업체에 갇히지 않고 이전 가능 |

**운영 비용 구조**: 정적 화면과 관리형 백엔드 조합이라, 초기 운영비는 **월 수만 원 수준**에서 시작할 수 있습니다. 사용량에 비례해 늘어납니다.

## 6. 품질 검증

- 기능별 **자동화 브라우저 테스트 약 300건**: 편집, 저장, 발행, 비밀 링크, 저작권 보호, 관리자, 가입·탈퇴를 다룹니다.
- 실서버 검증: 보안 규칙, 서버 함수, 탈퇴 즉시 파기
- 실제 사용자 테스트 피드백을 반영하는 반복 개발 체계

## 7. 개발 현황과 로드맵

**완료 (MVP)**: 편집기, 자동 저장, 글 흐름 엔진, 미디어 배치, 책장 넘김 열람, 서가·비밀 링크, 인쇄본 QR, 저작권 보호, 관리자 대시보드, 회원 정보 관리, 약관·개인정보·탈퇴
