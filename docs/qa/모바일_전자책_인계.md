## 1. 왜 하는가 (정선C의 배경)
- 노인종합복지관에 모아를 소개했고 **긍정적으로 검토 중, 곧 미팅**. 복지관은 "6주간 3명, 연 3회" 규모로 **AI 자서전 쓰기** 업체를 알아보는 중.
- 복지관이 원하는 것: **휴대폰으로 모아를 쓰는 것.** 휴대폰에서 AI와 글을 쓰고, **전자책과 PDF까지** 만들어야 함.
- 대표(정선C)는 개발 초보 → 새 작업은 **왜 필요한지 쉬운 비유로 먼저**, 할 일은 단계별로. 비밀 키·토큰은 채팅에 받지 않는다(정선C가 대시보드에 직접 입력).

## 4. 목표 범위: "폰에서 글쓰기 → 전자책·PDF"
### 지금 있는 것(재사용)
- AI와 쓰기: `studio/ai-proto.js`(편집기 옆 창, 로그인 + `ai_enabled` + 동의한 회원만). 폰용 **전체 화면 대화**로 바꿔야 함.
- 책 넘김 보기: `lib/book-viewer.js`(폰은 한 쪽씩). `lib/book-render.js`(쪽 그리기).
- 저장·서가 공개·비밀 링크·사진/영상/노래 올리기(`lib/media-client.js` + `media` 함수).
- 내려받기(`studio/index.html`의 `exportPages`, `#btnExport`): **화면용 전자책(HTML 한 파일)** 과 **인쇄용 전자책(신국판, QR)**.

### 없는 것(새로 만들 것)
1. **폰 전용 쉬운 흐름.** 지금 편집기(`studio/index.html`)는 마우스로 글상자를 끌고 쪽을 배치하는 **컴퓨터용**. 폰에서 쓰기 어렵고 어르신에게도 어려움 → "AI 글 + 사진 → **자동 쪽 나누기** → 미리보기" 흐름이 필요. 글 흐름 엔진(`flowFrom`, `reflowAll`, `settle`)은 `docs/DESIGN.md` "글 흐름 엔진" 참고.
2. **PDF**: `docs/DESIGN.md`에 "앞으로"로만 있고 **아직 없음**(PDF 내려받기는 print 사진 사용 예정, DESIGN 표 참고).
3. (확인 필요) **EPUB**: 전자책 앱용 파일이 필요한지. 지금은 HTML 한 파일.

### PDF 방법 3가지
| 방법 | 장점 | 한계 |
|---|---|---|
| ① 브라우저 "PDF로 저장"(인쇄용 모양 맞춰 두기) | 가장 빠르고 무료 | 어르신에게 안내 필요, 폰마다 결과 차이 |
| ② 폰 안에서 PDF 직접 생성 | 한 번 누르면 끝 | 한글 글꼴을 파일에 넣어야 해 무거움 |
| ③ 서버에서 PDF 생성 | 결과 일정·인쇄소 품질 가능 | 별도 서비스·비용·작업 |
- **추천: ①로 시작 → 쓰는 분들 반응 보고 ③**. 첫 수업(6주 3명) 시연은 ①로 충분.

## 5. 제안 순서
1. **폰 점검**(웹 또는 데스크탑): 현재 모아(로그인·AI와 쓰기·서가·내려받기)를 아이폰/갤럭시 크기로 열어 캡처 → "어디가 되고 어디가 깨지는지" 목록. 이걸로 작업량 확정. 결과는 쉬운 말로 정리(미팅 자료로도 사용).
2. **폰 전용 흐름 시제품**: 전체 화면 AI 대화 → 사진 한두 장 붙이기 → 자동 쪽 나누기 → 미리보기(책 넘김 보기).
3. **출력**: 폰에서 HTML 전자책 받기 + PDF(①). 인쇄용 모양(신국판) 정리.
4. 반응 보고 서버 PDF·EPUB 추가.

### 정선C가 미팅에서 확인할 것(결정 필요)
- 폰이 아이폰/갤럭시 중 무엇이 많은지, 스마트폰을 쓰는 어르신 비율.
- 폰으로 **글쓰기까지** 원하는지, 읽기·사진·녹음만으로도 되는지.
- PDF를 어디에 쓰는지(폰에서 읽기 vs 인쇄소 납품), 전자책 앱용(EPUB) 필요 여부.
- 카카오톡으로 링크를 받아 열게 되는지(**카톡 인앱 브라우저** 대응 필요).
- 복지관 와이파이 사용 가능 여부, 수업 진행자(직원인지 정선C인지), 예산·선정 방식.
- 비용: AI는 회원 1명 하루 상한 3,000원, 실제로는 한 세션(22회 호출) 약 700원. 6주×3명 예상 비용 추정은 아직 안 만듦.

## 6. 반드시 지킬 원칙 (CLAUDE.md 요약)
- **저작권 보호 최우선**: 서가·비밀 링크는 복사·인쇄·내려받기 차단, 미디어는 서명 주소로만. PDF/전자책을 폰에 추가해도 **작가 본인만** 받을 수 있게(독자에게 내려받기 열지 않기).
- "영구 보존"을 약속하지 않는다(내보내기 우선). 개인정보 처리방침(`privacy/`)과 실제 동작이 항상 일치해야 함 — 폰에서 새로 수집·전송하는 게 생기면 처리방침도 함께 고칠 것.
- 사실과 다르게 과장하지 않는다(AI 기능이 없으면 있다고 쓰지 않음).
- 비밀 키·토큰은 채팅에 받지 않는다.
- AI 지침서(최종)는 **저장소에 올리지 않는다**: DB `ai_prompts`에서만. 로컬 사본 `tests/ai-lab/private/v44.mjs`는 `.gitignore`라 **데스크탑에는 없음**(필요하면 정선C의 설계 문서 링크나 DB에서 가져올 것).
