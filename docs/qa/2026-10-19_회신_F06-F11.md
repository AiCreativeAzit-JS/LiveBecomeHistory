## F06 설명 글상자가 완전히 겹침

- **상태**: 재현됨 → 수정
- **원인**: `addCaption()`이 주변 상자를 보지 않고, 누를 때마다 사진 바로 아래 같은 좌표에 새 상자를 만들었습니다. 그래서 틀의 설명 자리와도 겹쳤습니다.
- **변경 내용**:
  - **사진과 설명 연결**: 사진·영상·노래 바로 아래에 있는 설명 상자를 그 미디어의 설명으로 봅니다.
    - 기준 범위: 미디어 아래 14mm 안. 자리에 맞춰 넣은 사진은 원래 자리 아래 기준
    - 대상: 틀의 설명 자리(안내 글이 있는 상자), 또는 4줄 높이 이하의 글상자
  - **이미 설명이 있으면**: 새로 만들지 않고 그 상자를 편집 상태로 엽니다. 틀의 설명 자리가 먼저 쓰입니다. 단추 이름도 「설명 글 고치기」로 바뀝니다.
  - **설명이 없으면**: 사진 아래의 **빈자리**(다음 상자가 시작하기 전까지)에 사진 폭에 맞춰 새 상자를 놓습니다.
  - **아래 빈자리가 모자라면**: 위치와 비율은 그대로 두고, 사진·영상을 설명 두 줄이 들어갈 만큼 줄입니다. 「설명 자리를 만들려고 사진을 조금 줄였어요 (Ctrl+Z로 되돌리기)」라고 알립니다. 40% 넘게 줄여야 하거나 노래 카드라면 상자를 만들지 않습니다. 대신 「아래에 설명을 넣을 빈자리가 없어요. 크기를 줄이거나 아래 상자를 옮긴 뒤 다시 눌러 주세요」라고 안내합니다.
- **T21 결과**: 통과.
  - 3쪽 사진 자리에 세로 사진을 넣고 「설명 글 넣기」를 두 번 눌렀습니다. 두 번 모두 틀의 설명 자리 하나만 열렸고, 상자 수는 그대로였으며 겹침도 없었습니다.
  - 틀의 설명을 지운 뒤에는 새 상자 1개가 사진 아래에 생겼고, 다시 누르면 그 상자가 열렸습니다(3번째 상자 없음).
  - 책으로 그린 쪽에도 설명이 한 번만 나왔습니다.
- **T22 결과**: 통과.
  - 쪽 맨 아래 사진: 사진을 비율 그대로 줄여 설명을 넣었습니다(겹침·잘림 없음, 안내 표시). Ctrl+Z로 원래대로 돌아갔습니다.
  - 쪽 맨 아래 노래: 아무것도 바꾸지 않고 안내만 했습니다.
  - 바로 아래 본문이 있는 사진: 본문과 겹치지 않게 사이에 넣었습니다.

## F11 페이지 활성화 뒤 키보드 탐색이 끊김

- **상태**: 재현됨 → 수정
- **원인**: 쪽을 열면 썸네일 목록을 통째로 다시 그리는데, 포커스를 받던 칸도 그때 사라졌습니다. 방향키 분기만 새 썸네일에 포커스를 줬습니다.
- **변경 내용**:
  - 썸네일마다 쪽 ID(`data-id`)를 달았습니다.
  - 목록을 다시 그릴 때 포커스가 목록 안에 있었으면 **같은 쪽 ID의 같은 칸**(썸네일·✓·복제·삭제)으로 돌려놓습니다. 지워진 쪽이면 지금 쪽 썸네일로 갑니다.
  - Enter·Space·방향키·마우스 클릭·Delete 모두 같은 규칙으로 도착합니다.
  - 지금 쪽에는 `aria-current="page"`를 달았습니다. 키보드 포커스 테두리(`:focus-visible`)는 그대로 보입니다.
- **T27 결과**: 통과.
  - 2쪽 썸네일 Enter → ↓↓ → 4쪽(포커스도 4쪽)
  - ↑ 뒤 Space → ↓ → 4쪽
  - Delete로 쪽을 지운 뒤에도 포커스가 썸네일에 남음
  - 마우스로 연 뒤 ↓도 이어짐

## F07 남은 부분: 팝업 닫을 때 포커스 복원

- 팝업(내려받기·새 쪽 종류·공유·가입 안내·미리보기)이 닫히면 열기 전 자리로 포커스를 돌려줍니다. 포커스가 팝업 안에 있었거나 빠졌을 때에 해당합니다.
- Esc·「닫기」 단추 모두 확인했습니다(내려받기·새 쪽 종류·미리보기).
