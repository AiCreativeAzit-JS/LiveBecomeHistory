# 인물대백과사 · 멀티 전자책 에디터 — 설계 v1

## 원칙 (모든 결정에 우선한다)
1. **"영구 보존"을 약속하지 않는다.** 대신 "언제든 내 책을 통째로 내려받을 수 있다"와
   "서비스 종료 시 사전 고지 + 모든 책 반환"을 약속한다.
2. **내보내기 우선.** 책은 열린 형식(HTML + 원본 미디어 파일)으로 언제든 내려받을 수 있어야 한다.
3. **이사 가능한 표준 기술.** Postgres + S3 호환 저장소. 특정 회사에 종속되는 기능을 피한다.
4. **본인 책은 본인만, 공개한 책만 서가에서.** 보안은 화면이 아니라 DB 규칙(RLS)이 지킨다.
5. **랜딩(archive4everyone `main`)과 아스트라의 Supabase(`archive4everyone-mvp`)는 건드리지 않는다.**

## 구성
- 호스팅: GitHub Pages(정적). 에디터는 HTML/JS + supabase-js, 서버 없음.
- 백엔드: Supabase 프로젝트 `archive4everyone-editor` (서울). 무료 플랜은 개발용. **실제 회원을 받기 전 유료 전환 필수.**
- 경로: `/editor`(작성) · `/shelf`(서가) · `/admin`(관리자)

## DB
| 테이블 | 용도 |
|---|---|
| profiles | 회원 프로필(가입 시 자동 생성) |
| admin_users | 관리자 목록(일반 사용자 접근 불가, SQL로만 지정) |
| books | 책. `is_public`은 작가, `admin_hidden`은 관리자만 변경 |
| chapters | 장. 정제된 HTML 본문 |
| media | 이미지·영상·노래(파일 또는 https 링크) |
| reports | 서가 신고 |
| book_admin_notes | 관리자 메모(관리자 전용) |
| shelf_books (뷰) | 서가 목록. 공개·비숨김·미삭제 책만 |

저장소: 비공개 버킷 `book-media`(파일당 50MB). 경로 규칙 `{user_id}/{book_id}/파일명`.
공개된 책의 파일만 타인이 읽을 수 있다.

## 보안 점검 결과
- RLS 전 테이블 적용, 도우미 함수는 외부 비노출 `private` 스키마.
- 시나리오 테스트 10건 통과(익명/타인/본인 시점의 서가·책·챕터 노출, 프로필 자동 생성).
- 남은 경고: `admin_set_hidden` 함수(로그인 사용자 실행 가능). 함수 내부에서 관리자만 통과시키므로 의도된 동작.

## 관리자 (4단계 완료)
- 경로 `/admin/`. 로그인 후 `am_i_admin()`으로 관리자 여부 확인. 화면은 정적이며 **실제 권한은 DB 규칙(RLS)이 강제**한다.
- 기능: 대시보드 통계, 신고 처리(책 숨기기+처리 완료 / 처리 완료 / 문제없음 / 다시 열기), 책 관리(공개·숨김·나만 보기·삭제 필터, 숨김/해제, 관리자 메모), 회원 목록.
- 개인정보 원칙: 비공개 책의 본문은 관리자 화면에서 열지 않는다(제목·지은이 등 기본 정보만).
- 관리자 지정은 SQL로만: `insert into public.admin_users (user_id) select id from auth.users where email = '...';`
- 검증: 실제 DB에서 권한 14건(일반 회원 차단, 작가의 admin_hidden 직접 수정 차단, 관리자 숨김·메모·신고 처리) 통과.

## 업로드 한도 (확정)
| 종류 | 한도 | 비고 |
|---|---|---|
| 사진 | 15MB | 화면에서 확인 |
| 노래 | 30MB | 화면에서 확인 |
| 영상 | 50MB (약 50초) | 저장소 버킷 한도 50MB(무료 플랜 상한과 동일) |
| 책 한 권 합계 | 200MB | DB 트리거(`media_quota`)가 강제 |

## 새 에디터 `/studio/` (시안 단계)
- 방향: 밝고 연한 톤, 3단 구성(페이지 목록 · 신국판 캔버스 · 도구). 스무고개는 별도 서비스로 분리.
- 페이지 기반 고정 레이아웃: 한 페이지 = 신국판 152×225mm, 기본 글자 12pt.
  글은 인디자인식 글상자(끌어서 이동, 손잡이로 크기 조절, 넘침 경고). 사진·영상·음악은 새 페이지에 담고, 설명은 글상자로 추가.
- 좌표는 mm로 저장하고 화면에서는 페이지 너비 비율(%, cqw)로 그려 확대율·기기·내보내기에서 같은 모습.
- 현재는 데이터 저장 없는 시안. 확정 후 DB `pages` 테이블(요소 목록 jsonb)로 연결하고 기존 `chapters` 책은 변환한다.
- 외부 CDN 부품 없이 순수 HTML/JS(장기 운영 시 외부 의존 최소화).

### 스튜디오 편집 규칙 (워드 방식, v2)
- 여백 고정: 좌우 16mm · 위아래 18mm(본문 폭 120mm). 글상자·사진은 끌기·크기 조절·방향키 모두 여백 안에서만 움직인다. 편집 화면에만 금색 점선 안내선.
- 글상자는 한 번 만들면 비어 있어도 남는다. 모든 글상자는 연한 점선, 빈 상자는 옅은 바탕 + "여기를 눌러 글을 입력하세요".
- 글상자를 한 번 누르면 누른 자리에 커서. 입력 중에도 모서리 손잡이·「옮기기」 손잡이로 크기·위치 조절.
- 글을 쓰면 상자가 아래 여백까지 자란다. 페이지에 자리가 없으면 「글」이 새 페이지를 만들고, 새 페이지는 본문 전체가 글상자.
- 글자를 드래그하면 미니 도구 창(굵게·기울임·밑줄·7색·다른 색·꾸밈 지우기). 오른쪽 패널 색·굵게도 고른 글자에만 적용, 고르지 않았으면 상자 전체.
- 허용 서식: b/i/u, span의 color·font-weight·font-style·underline만(나머지 스타일은 정제 단계에서 제거). 붙여넣기는 글자만.
- 페이지 다루기(파워포인트 방식): 썸네일 위 복제·삭제 버튼, 썸네일 사이 ＋로 끼워 넣기, 오른쪽 클릭 메뉴(앞/뒤에 새 페이지·복제·옮기기·삭제), 썸네일에서 Delete 키. 내용이 있는 페이지만 삭제 확인, 모두 Ctrl+Z로 되돌리기.
- 글자 크기: 숫자를 누르면 목록(8~60pt). 밑줄은 패널·미니 도구 창 모두 제공.
- 자동 넘김: 글상자가 아래 여백까지 자란 뒤에도 넘치면 넘친 글을 다음 '이어서' 페이지로 옮기고 커서도 따라간다(단어 중간에서 자르지 않음, 연쇄 넘김 지원). 이어서 페이지는 `flowFrom`으로 앞 페이지를 기억.

## 스튜디오 실제 저장 (완료)
- 주소: `/studio/?book=<책 번호>` = 내 책 편집(로그인 필요). 주소에 book이 없으면 저장 안 되는 시안 모드.
- DB: `books.format`(`chapters`=옛 에디터, `pages`=스튜디오), `pages` 표(페이지 순서·이름·배경·자동 넘김 연결·요소 목록 jsonb). RLS는 chapters와 같음.
- 자동 저장: 1.5초마다 바뀐 부분이 있으면 전체 페이지를 upsert하고, 지운 페이지는 DB에서도 삭제. 탭을 닫거나 숨길 때도 저장.
- 미디어: 저장소 업로드 → media 표 → 페이지에는 `media_id`만 저장(주소는 열 때마다 새로 발급, 6시간 유효).
- 옛 책 옮기기: 스튜디오에서 처음 열면 장 → 표지+글 페이지+사진·영상·음악 페이지로 변환하고 긴 글은 자동 넘김. **원본 chapters는 지우지 않는다.**
- 서가: format=pages 책은 `lib/book-render.js`로 페이지 모양 그대로. 저장 데이터를 믿지 않고 좌표·색·태그·미디어 주소를 모두 다시 검사.
- 내려받기: 15MB 이하 미디어는 HTML 안에 넣고, 큰 파일은 7일 유효 링크.
- 알려진 한계: 페이지에서 지운 사진·영상 파일은 저장소에 남는다(추후 정리 규칙). 앞 페이지 글을 지워도 뒤 페이지 글이 당겨 오지 않는다.
- 새 책 견본 3쪽(표지·첫 번째 이야기·기억하고 싶은 순간): 회색 안내 글(`ph`, 글을 쓰면 사라짐, 썸네일에도 보임)과 사진 자리(`slot`). 사진 자리를 누르면 사진을 골라 **그 자리에** 비율을 지켜 넣는다(새 페이지 아님). 안내 글·사진 자리는 책(미리보기·내려받기·서가)에는 나오지 않는다.
- 견본 5쪽: 표지 · 첫 번째 이야기 · 기억하고 싶은 순간(사진 자리) · 8초의 영상(영상 자리) · 나의 노래(노래 자리 + 가사 안내).
- 내 서재 = 책 관리: 카드의 ⋯ 메뉴(열기·이름 바꾸기·서가 공개/내리기·서가에서 보기·휴지통으로), 휴지통 탭(되살리기·완전히 지우기). 완전히 지우기는 「삭제」 입력 확인 후 저장소 파일까지 삭제.
- 서가 인쇄: 새 형식 책은 `@page 152mm×225mm`, 한 쪽 = 종이 한 장. 「인쇄·PDF」 버튼. 옛 형식 책은 잘림 안내.
- 쪽 바로가기 주소: `/shelf/#/book/<책>/p/<쪽>` (QR 코드가 가리킬 주소).
